# Exporting reports from TallyPrime

These pages describe which TallyPrime reports to export and the settings that give the best results.

> **TODO(review): R-07** — exact TallyPrime menu paths and option names are not written here because they could not be verified against TallyPrime documentation. Each page marks where the path belongs.

Files are read in your browser. Only file names, sizes, sheet counts and row counts are shown before you run a paid action.

| Report                                    | Use                                                                                              |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------ |
| [Trial Balance](trial-balance.md)         | The ledger balances every MIS is built from. Needed for company setup and every monthly refresh. |
| [Profit & Loss A/c](profit-and-loss.md)   | Used to check the MIS income statement against the books.                                        |
| [Balance Sheet](balance-sheet.md)         | Used to check assets and liabilities at month end.                                               |
| [Group Summary](group-summary.md)         | A single group with its ledgers, most often Sundry Debtors or Sundry Creditors.                  |
| [Ledger Vouchers](ledger-vouchers.md)     | Every voucher that touched one ledger, e.g. a bank account.                                      |
| [Day Book](day-book.md)                   | Voucher-level detail for the period.                                                             |
| [Sales Register](sales-register.md)       | Invoice-level sales with GST.                                                                    |
| [Purchase Register](purchase-register.md) | Invoice-level purchases with input GST.                                                          |
| [Stock Summary](stock-summary.md)         | Closing quantities and values by item.                                                           |
| [Bills Receivable](bills-receivable.md)   | Outstanding customer bills with due dates, used for ageing.                                      |
| [Bills Payable](bills-payable.md)         | Outstanding supplier bills with due dates, used for ageing.                                      |
| [Pay Sheet](pay-sheet.md)                 | Salary components by employee for the month.                                                     |
